# الميل الثاني: تطبيق مدارس الأحد

React + TypeScript + Vite + Tailwind. قاعدة البيانات والدخول على **Supabase**، والنشر على **Vercel**. بالعربي (RTL)، بيشتغل **أوفلاين**، وكل التحقق والصلاحيات على السيرفر.

## إيه اللي في التطبيق
- **المخدوم:** اختبارات ونجوم، متجر هدايا (بكمية اختيارية)، حضور بالموقع، فارس الإنجيل (قداس/اعتراف/مزامير/أجبية)، «هات أخوك»، المتصدرون، ملف شخصي، رسائل (الجرس).
- **الخادم:** إدارة فصله (اختبارات، هدايا، حضور، غياب، تحضير الدروس بالذكاء الاصطناعي، نقل الفصول) وتسجيل فارس الإنجيل بيوم وساعة الاعتراف.
- **الأدمن:** اعتماد الخدام، دليل المستخدمين (الضغط على الاسم يفتح خياراته)، طلبات كلمة السر، إعدادات الكنيسة والفصول، و**اقتراحات للتطوير** (يكتب فكرة ويبعتها لصانع التطبيق ويتابع حالتها).
- **صانع/صاحب التطبيق:** الأدمن يجعل خادم أو مخدوم «صانع تطبيق»، فتظهر له صفحة «اقتراحات التطبيق»: بيستلم اقتراحات الأدمن (مع زر نسخ المواصفات وتغيير الحالة)، ويبعت أفكاره هو كمان.
- **كلمة السر:** استعادة بطلب للأدمن + كلمة مؤقتة 30 دقيقة على الإيميل، وتغيير إجباري بعد الدخول بيها.
- **الأوفلاين:** نسخة كاملة من البيانات على الجهاز، وأي كتابة بتتحفظ وتتبعت لما النت يرجع.

## تركيب من الصفر (مشروع جديد)
### 1) Supabase
1. أنشئ مشروع جديد. من **Authentication ثم Sign In / Providers ثم Email** اقفل **Confirm email**.
2. من الطرفية جوه مجلد المشروع:
   ```bash
   npm i -g supabase          # أو استخدم npx supabase
   supabase login
   supabase init              # مرة واحدة (بيعمل supabase/config.toml ومش بيمس migrations)
   supabase link --project-ref <ref-بتاع-مشروعك>
   supabase db push           # بيشغّل كل ملفات supabase/migrations بالترتيب
   ```
3. **حساب الأدمن:** افتح `supabase/seed_admin.example.sql`، غيّر اسم المستخدم وكلمة السر (12 حرف على الأقل)، شغّله مرة واحدة من SQL Editor، وامسح كلمة السر من الملف.
4. **Database ثم Extensions:** فعّل **pg_cron** (عشان الكلمة المؤقتة تنتهي في وقتها بالظبط).
5. لو شغّلت النسخة القديمة اللي فيها الشات: `db push` هيشغّل كمان `20261029100000_cleanup_chat_leftovers.sql` (بيمسح بقايا الشات). وامسح bucket اسمه `chat-media` من Storage لو موجود.

### 2) الإيميل (ترحيب الخادم/المخدوم + كلمة السر المؤقتة)
1. حساب على [Resend](https://resend.com) ومفتاح API. للإرسال لأي حد لازم تفعّل دومين بتاعك (من غير دومين بيبعت لإيميل صاحب الحساب بس).
2. ```bash
   supabase secrets set RESEND_API_KEY=re_xxx MAIL_FROM="الميل الثاني <no-reply@دومينك>" APP_URL=https://رابط-موقعك
   supabase functions deploy send-email
   ```
   (خلّي **Verify JWT** شغّال للدالة دي.)

### 3) Vercel (Settings ثم Environment Variables)
| المتغير | القيمة |
|---|---|
| `VITE_SUPABASE_URL` و`SUPABASE_URL` | رابط مشروع Supabase |
| `VITE_SUPABASE_ANON_KEY` و`SUPABASE_ANON_KEY` | المفتاح العام (publishable)، **مش** service_role أبدًا |
| `GEMINI_API_KEY` | لتحضير الدروس والصوت |
| `GEMINI_MODEL` | اختياري (الافتراضي `gemini-flash-latest` (اسم مستعار بتحدّثه Google لوحدها لآخر موديل Flash)) |
| `TTS_MODEL` | اختياري |

بعد أي تغيير في المتغيرات اعمل **Redeploy**. (`VITE_*` بتتقرا وقت البناء، و`SUPABASE_*` بيقراها السيرفر.) لو تركتهم فاضيين بيتستخدم المشروع المكتوب افتراضيًا في `src/lib/supabase.ts` و`api/_supabase.js`.

### 4) اختبار بعد النشر (10 دقايق)
1. سجّل دخول بالأدمن، وسجّل خادم ومخدوم تجريبيين (بإيميلك)، واعتمد الخادم: لازم يوصل إيميل ترحيب.
2. «نسيت كلمة السر» لحساب تجريبي، وافق من «طلبات كلمة السر»: لازم توصل كلمة مؤقتة، والدخول بيها يطلب تغيير.
3. فعّل «جعله صانع تطبيق» لخادم (دليل المستخدمين ثم الضغط على الاسم)، وابعتله اقتراح من «اقتراحات للتطوير»، وادخل بحسابه وشوفه وجرّب «نسخ المواصفات» وتغيير الحالة.
4. اقفل الإنترنت وافتح صفحات مختلفة وسجّل حضور أو تسميع: لازم يتحفظ ويتبعت لما النت يرجع.
5. جرّب الكاميرا («هات أخوك») والموقع (الحضور) وتصدير PowerPoint (بعد رؤوس الأمان في `vercel.json`).

## الأمان (على السيرفر مش في الواجهة)
- النجوم والاختبارات والاستبدال وفارس الإنجيل والمسابقات والاستمارات بتتحسب في دوال Supabase (RPC)؛ المستخدم مش بيكتب نتايجه مباشرة. RLS: الخادم يشوف فصله بس والأدمن الكل.
- صلاحية «صانع التطبيق» في جدول منفصل مقفول (مش في جدول المستخدمين) فمحدش يرقّي نفسه.
- الاقتراحات: بتتبعت وتتقرا بدوال على السيرفر بس (الجداول مقفولة)، وبتتنضّف من محارف التحكم والاتجاه، وفيها حد يومي.
- الذكاء الاصطناعي: مفتاح Gemini على السيرفر بس، وحد يومي لكل مستخدم، وفحص الهوية قبل أي حاجة.
- `vercel.json`: CSP صارمة وHSTS ومنع الـ iframe وسياسة صلاحيات المتصفح. لو ميزة وقفت بعد النشر غيّر مؤقتًا الهيدر إلى `Content-Security-Policy-Report-Only` وراجع Console.

## حدود معروفة
- التحضير بالذكاء الاصطناعي والصوت بيحتاجوا نت.
- إجابات الاختبارات بتوصل لمتصفح المخدوم، وده محتاج view أو دالة لاحقًا لإخفائها.
- صور الذكاء الاصطناعي من خدمة مجانية (Pollinations)، والصوت داخل البوربوينت تجريبي.
- الصفحات الديناميكية اتلغت من التطبيق. لمسح بياناتها القديمة: `supabase/optional/remove_dynamic_pages.sql` (اختياري ومش بيتشغّل لوحده).

## أوامر
`npm ci` ثم `npm run dev` للتطوير، `npm run build` للبناء، `npm run typecheck` و`npm run lint` للفحص.
